## Configuration du projet avec Composer

Mise en place d'une structure pour un projet web en utilisant variables d'environements

### Etapes à faire pour lancer le projet

1. Depuis le terminal, dans le dossier du projet

```bash
composer install
```

2. Copier le fichier ./config/env/.env.conf à la racine du projet avec les information de votre environnement

```bash
cp ./config/env/.env.conf ./.env
```
